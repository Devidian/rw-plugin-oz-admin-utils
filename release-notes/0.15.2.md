# OZ Admin Utils 0.15.2

Map source retention can now remove surface chunks seven days after their last scan, once a renderer has confirmed the matching version. Cleanup is disabled by default and deletes at most 1,000 confirmed chunks per minute. The renderer token is optional for normal plugin operation.

The cleanup setting and export-route group now have German and English descriptions. Existing world settings and map data are preserved when updating; database columns are added without rebuilding stored chunks.

For cleanup, first update the renderer to 0.1.7, retain its tile and source-cache storage, complete a full sync, and configure the same private token as `mapRendererAckToken` in Admin Utils and `mapAckToken` in that world's renderer entry. Then enable `mapSourceCleanupEnabled`. Keep one authoritative renderer per world. Without these settings, map capture and rendering continue as before.

Requires Java 25 and OZ Tools 0.28.2.
