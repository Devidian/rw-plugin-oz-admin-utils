# OZ Admin Utils 0.13.0

- Set a minimum world play time before any player, including administrators, can place blueprints; 0 disables the limit.
- Protect NPCs against leashing and animal theft, with escalating penalties for repeated attempts.
- Configure Discord report channels together; channel ID 0 disables the respective report.

Requires OZ Tools 0.26.3 or newer. Existing JSON settings should be reviewed when upgrading because the former report switches are no longer used.
