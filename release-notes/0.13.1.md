# OZ Admin Utils 0.13.1

- Configure and run scheduled or manual server restarts in Admin Utils. Set an IANA time zone such as `Europe/Berlin` for schedules independent of the server's local clock.
- Announce scheduled restarts 10 and 5 minutes early, then show a localized on-screen and chat countdown while waiting for players.
- Keep the game-owned `Player.db` and its write-ahead log intact when reading persisted player data for Manager exports.

Copy existing restart permissions and times manually from Discord Connect's world JSON into Admin Utils's world JSON. The default `system` time zone retains server-local scheduling. Admin Utils now defaults to the native `restart` command; existing `useShutdownNotRestart=true` settings still send `shutdown` and require an external supervisor to restart the server. Requires OZ Tools 0.27.3 or newer.
