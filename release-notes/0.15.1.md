# OZ Admin Utils 0.15.1

- Blueprint provenance now checks whether the server's PluginAPI provides the required blueprint count and hash methods. If they are missing, provenance checks and blueprint Discord reports are disabled with a startup warning; the existing play-hour rule stays active.
- Blueprint creation and placement reports use the configured Discord thread routing, verified on the Development server.

Existing world settings and blueprint records are preserved. Requires Java 25 and OZ Tools 0.28.2. Full blueprint provenance and reports require the blueprint fingerprint methods available in Rising World PluginAPI 0.9.3.2.
