# OZ Admin Utils 0.15.0

- Optionally restrict blueprints that were not created on this server. Set `maxConstructionCountInExternalBlueprints` to `0` to check every blueprint or to a positive construction count to check larger blueprints. The default `-1` leaves the restriction off.
- Administrators can bypass both the blueprint origin and play-time rules by default. Set `blueprintAdminExempt=false` to apply both rules to them.
- Configure optional Discord channels for blueprint creation and allowed or blocked placement attempts. Players receive a localized native message when a placement is rejected.

Blueprints created before provenance recording began are treated as external when the check applies. Existing world settings and data remain in place. Requires Java 25 and Rising World PluginAPI 0.9.3.2.
